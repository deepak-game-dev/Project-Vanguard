# Project Vanguard

A C++ gameplay programming project focused on learning how to connect multiple gameplay systems into a working architecture.

## Overview

Project Vanguard is a Phase 2 project in my AAA Gameplay Engineer learning roadmap. Its primary goal is to understand how individual C++ systems communicate and work together to support gameplay.

## Learning Objectives

- Understand gameplay architecture and system integration.
- Connect input handling with player movement.
- Explore camera-related gameplay concepts.
- Implement collision handling.
- Introduce basic enemy AI and perception.
- Practise organizing gameplay code into reusable components.

## Core Systems

- Gameplay Architecture
- Input System
- Player Movement
- Camera System
- Collision System
- Basic AI and Perception

## Technologies

- C++
- Visual Studio

## Project Purpose

This project builds the foundation for more advanced gameplay engineering by focusing on the connections between gameplay systems rather than treating each system as an isolated feature.
